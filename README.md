ProjectHelix
===========

Getting started
---------------

To get started with ProjectHelix, you'll need to get familiar with [Source Control Tools](https://source.android.com/setup/develop).

To initialize your local repository using the ProjectHelix trees, use a command like this:
```
repo init -u https://github.com/ProjectHelixOSS/android.git -b lineage-23.2 --git-lfs
```
Then to sync up:
```
repo sync
```
